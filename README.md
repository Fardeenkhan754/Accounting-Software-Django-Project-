# Accounting Software

A modern desktop accounting application built with **Python**, **Django**, **SQLite**, **Bootstrap**, and **JavaScript**.

## Features

### Dashboard
- Business overview
- Quick access to all modules

### Customer Management
- Add new customers
- Edit customer details
- Delete customers
- Search customers

### Income & Expense
- Record income entries
- Record expense entries
- Daily transaction history

### Cash Book
- Debit/Credit entries
- Running balance calculation
- Date-wise records

### Ledger
- Customer ledger
- Complete transaction history
- Balance calculation

### Backup System
- One-click database backup
- Automatic backup limit (Maximum 3 backups)
- Restore backup

### Reports
- Date-wise reports
- Income report
- Expense report
- Customer report

### User Interface
- Responsive Bootstrap design
- Easy navigation
- Clean interface

## Technology Stack

- Python 3
- Django
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
